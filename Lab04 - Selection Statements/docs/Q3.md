# Lab 4 Q3 · Menu restoran dengan `switch`

[Indeks Lab 4](../README.md) · [Kode Java](../Lab4Q3_RestaurantOrder.java)

Pilih makanan atau minuman dari menu menggunakan `switch`. Minta kuantitas hanya untuk kode 1–4. Kode 0 keluar; kode bilangan bulat lain menampilkan pesan pilihan tidak valid.

## PAC

| Bagian | Isi |
| --- | --- |
| Given Data | Kode menu (`choice`), harga tetap dari menu, dan kuantitas jika pilihan 1–4. |
| Required Results | Nama item terpilih, harga satuan, kuantitas, dan total; atau pesan keluar / pilihan tidak valid. |
| Processing Required | Gunakan `switch` untuk memetakan kode ke item dan harganya. Untuk kode 1–4, baca kuantitas dan kalikan dengan harga. |
| Solution Alternatives | Rangkaian `if` juga bisa memilih satu item, tetapi lembar meminta `switch` / `case`. |

## IPO

| Input | Processing | Module/Method Reference | Output |
| --- | --- | --- | --- |
| Kode menu (`choice`), harga tetap dari menu, dan kuantitas jika pilihan 1–4. | Gunakan `switch` untuk memetakan kode ke item dan harganya. Untuk kode 1–4, baca kuantitas dan kalikan dengan harga. | Main | Nama item terpilih, harga satuan, kuantitas, dan total; atau pesan keluar / pilihan tidak valid. |

## Pseudocode

```text
Algorithm:
Start
  Print menu
  Read choice
  Switch choice
    Case 1: item = "Steak", price = 29.50
    Case 2: item = "Grill chicken", price = 19.50
    Case 3: item = "Pasta", price = 15.00
    Case 4: item = "Drinks", price = 4.90
    Case 0: Print quit message
    Default: Print invalid choice message
  End Switch
  If choice >= 1 and choice <= 4 Then
    Read quantity
    total = quantity * price
    Print item, price, quantity, total
  End If
End
```

## Asumsi dan batasan

Frasa “and/or” pada lembar dapat dibaca sebagai beberapa pilihan dalam satu transaksi. Kode yang dipertahankan menangani **satu item per run**: tidak ada loop atau akumulasi beberapa item. Jalankan ulang untuk memilih item lain. Kode hanya memeriksa pilihan menu, bukan rentang kuantitas; masukkan bilangan bulat positif.
