# Lab 4 Q6 · Habis dibagi 3 dengan operator `?:`

[Indeks Lab 4](../README.md) · [Kode Java](../Lab4Q6_DivisibleBy3.java)

Ubah `if` / `else` dari soal menjadi operator kondisional. Tes sisa bagi, teks hasil, dan satu baris cetak tetap sama.

## PAC

| Bagian | Isi |
| --- | --- |
| Given Data | Satu bilangan bulat (`num`). |
| Required Results | `Divisible by 3 : ` atau `NOT Divisible by 3 : `, diikuti nilai `num`. |
| Processing Required | Hitung sisa `num % 3`. Operator `?:` memilih teks pertama jika sisanya nol; jika tidak, pilih teks kedua. Simpan di `result` dan cetak. |
| Solution Alternatives | `if` / `else` menghasilkan keluaran yang sama, tetapi latihan meminta bentuk `?:`. |

## IPO

| Input | Processing | Module/Method Reference | Output |
| --- | --- | --- | --- |
| Satu bilangan bulat (`num`). | Hitung sisa `num % 3`. Operator `?:` memilih teks pertama jika sisanya nol; jika tidak, pilih teks kedua. Simpan di `result` dan cetak. | Main | `Divisible by 3 : ` atau `NOT Divisible by 3 : `, diikuti nilai `num`. |

## Pseudocode

```text
Algorithm:
Start
  Read num
  result = (num % 3 == 0) ? "Divisible by 3 : " + num : "NOT Divisible by 3 : " + num
  Print result
End
```

## Asumsi dan batasan

`0` habis dibagi 3 karena sisanya nol. Aturan sisa nol juga berlaku untuk bilangan negatif, misalnya `-6`.
