# Lab 4 Q4 · Konversi `switch` hari ke `if`

[Indeks Lab 4](../README.md) · [Kode Java](../Lab4Q4_DayType.java)

Ganti struktur `switch` dari lembar dengan `if` / `else if` / `else` tanpa mengubah hasil untuk setiap kelompok kode hari.

## PAC

| Bagian | Isi |
| --- | --- |
| Given Data | Satu bilangan bulat (`day`). |
| Required Results | `Weekday`, `Weekend`, atau `unknown DAY` (persis seperti potongan soal). |
| Processing Required | Gunakan tes rentang inklusif untuk kode 1–5; gunakan tes 0 atau 6 untuk akhir pekan; selain keduanya masuk ke `else`. |
| Solution Alternatives | Kode 1 sampai 5 juga bisa dibandingkan satu per satu dengan operator OR, tetapi tes rentang lebih pendek. |

## IPO

| Input | Processing | Module/Method Reference | Output |
| --- | --- | --- | --- |
| Satu bilangan bulat (`day`). | Gunakan tes rentang inklusif untuk kode 1–5; gunakan tes 0 atau 6 untuk akhir pekan; selain keduanya masuk ke `else`. | Main | `Weekday`, `Weekend`, atau `unknown DAY` (persis seperti potongan soal). |

## Pseudocode

```text
Algorithm:
Start
  Read day
  If day >= 1 and day <= 5 Then
    Print "Weekday"
  Else If day == 0 or day == 6 Then
    Print "Weekend"
  Else
    Print "unknown DAY"
  End If
End
```

## Asumsi dan batasan

Kode `0` dan `6` sengaja masuk kelompok yang sama. Kode di luar 0–6 tidak ditolak oleh `Scanner` selama berbentuk bilangan bulat; program mencetak `unknown DAY`.
